# Target Action Prediction API

Учебный проект по машинному обучению: модель оценивает вероятность целевого действия пользователя на сайте по данным визита и рекламным меткам. Проект включает исследовательский ноутбук, пайплайн обучения и HTTP API на FastAPI для получения предсказаний.

## Состав проекта

```text
analysis.ipynb       # исследование данных и эксперименты
pipeline.py          # подготовка данных, обучение и сохранение модели
main.py              # FastAPI-приложение
model/model.pkl      # готовая обученная модель
data/*.json          # четыре примера входных данных для API
```

Исходные файлы `ga_sessions.csv` и `ga_hits.csv` намеренно не включены в репозиторий из-за размера. Чтобы обучить модель заново, поместите их в папку `data/`.

## Установка

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск API

```bash
uvicorn main:app --reload
```

После запуска доступны:

- `GET /status` — проверка доступности сервиса;
- `GET /version` — метаданные сохранённой модели;
- `POST /predict` — предсказание целевого действия;
- `GET /docs` — интерактивная документация Swagger UI.

Сервис по умолчанию открывается по адресу [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

Для запроса `POST /predict` используйте один из JSON-файлов из папки `data/` как тело запроса. Поля должны соответствовать схеме API: UTM-метки, сведения об устройстве и географии, а также признаки даты и экрана.

## Переобучение модели

После размещения исходных CSV в `data/` выполните:

```bash
python pipeline.py
```

Скрипт подготовит признаки, сравнит Logistic Regression, Random Forest, LightGBM и CatBoost по ROC-AUC, выберет лучшую модель и сохранит её в `model/model.pkl`.

## Примечание

Это учебный локальный проект. В production-версии потребовались бы версионирование данных и моделей, автоматизированные тесты, контейнеризация и мониторинг сервиса.
